# Visualization & UI Repository

This repository contains advanced visualization and user interface components for the Sentiment Analysis project.

## Overview
This phase provides comprehensive visualization tools and user interfaces:
- Interactive dashboards
- Advanced data visualizations
- Word clouds and text analysis
- Performance metrics visualization
- Real-time monitoring dashboards

## Files
- `dashboard.py` - Interactive dashboard application
- `visualizations.py` - Advanced visualization functions
- `word_cloud_generator.py` - Word cloud generation
- `performance_monitor.py` - Real-time performance monitoring
- `requirements.txt` - Python dependencies
- `static/` - Static web assets (CSS, JS, images)
- `templates/` - HTML templates

## Features
- **Interactive Dashboard**: Real-time sentiment analysis dashboard
- **Word Clouds**: Visual representation of most common words
- **Performance Metrics**: Model performance visualization
- **Data Distribution**: Sentiment distribution charts
- **Real-time Monitoring**: Live sentiment analysis monitoring
- **Export Functionality**: Export results and visualizations

## Prerequisites
- Trained models from Static Implementation
- Processed data from Data Preprocessing
- Dynamic prediction system

## Usage

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Dashboard**:
   ```bash
   python dashboard.py
   ```

3. **Generate Visualizations**:
   ```bash
   python visualizations.py
   ```
